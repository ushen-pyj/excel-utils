# Excel Utils

Excel toolbox built with Tauri 2, TypeScript, and Rust.

## Features

- Data cleaning: deduplicate values, split columns, merge columns
- Financial modeling: PMT, NPV, IRR
- Quick print: printable report preview from pasted table data

## Scripts

- `npm run dev`: start the Vite frontend
- `npm run tauri dev`: start the Tauri desktop app
- `npm run build`: build the frontend assets
- `npm run tauri build`: build the desktop app

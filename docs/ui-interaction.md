# excel-utils UI 设计与交互规范

启动时显示主页。用户可以直接点击最近文件，或切换到“打开”页选择 XLSX。工作簿在同一扇 Qt 窗口内打开，沿用 ONLYOFFICE 的网格、公式栏和工具栏。本文也保留了后续 React 业务面板的设计约定，供实现插件时使用。[项目架构](../README.md)

## 窗口布局与命令入口

| 区域 | 用户能做什么 | 约定 |
| --- | --- | --- |
| 主页 | 查看最近文件，点击名称继续编辑 | 左侧提供“主页”“打开”“工作区”“工具”。沿用 ONLYOFFICE 最近列表，按名称、位置、最近打开时间显示；长路径截断。历史为空时显示上游文件拖放入口。 |
| 工具 | 整理明细、核对与检查、统计分析 | 按用途选择工具。每个来源可调表头和明细范围，用样例核对列名和内容。后台运行期间显示进度动效，有可靠总量时展示确定进度。系统启用减少动态效果时使用静态反馈。 |
| 打开 | 浏览本地 XLSX，从最近使用的文件夹开始选择 | 沿用上游“打开”页的浏览按钮和“最近使用的文件夹”。点击文件夹时以该目录打开系统文件选择器。 |
| 工作区 | 打开本地文件夹，浏览目录并在多个工作簿标签间切换 | 进入时恢复上次的文件夹，左上角可切换最近 20 个工作区。从工作区退出后直接启动应用，会回到原工作区。各工作区分别保留工作簿标签、顺序和选中项，仅在显示标签时首次加载工作簿。点击右上角工具图标可查看全部工具，在对话框中使用所选工具。选择来源时默认使用当前工作区目录。 |
| 工作区文件 | 浏览目录树、新建工作簿 | 左侧文件图标或 Ctrl+Shift+E 打开。单击目录树条目可高亮选中，双击文件夹可展开或折叠，双击 XLSX 可在右侧打开。标题旁的新建按钮在选中目录、选中文件的同级或工作区根目录创建 XLSX。输入名称后回车创建并打开，Esc 取消。 |
| 工作区搜索 | 在当前文件夹和子目录的已保存 XLSX 中查找单元格 | 左侧搜索图标或 Ctrl+Shift+F 打开。点击搜索框旁的 `.*` 切换正则搜索，结果高亮匹配文本。结果按工作簿分组，显示匹配数、文本片段和单元格位置。支持折叠、翻页、单击或回车定位。Esc 返回文件树并保留查询。 |
| 快速打开 | 按文件名或路径查找当前工作区内的工作簿 | 顶部按钮或 Ctrl+Shift+O 打开。空格可组合多个片段。列表显示文件名和相对目录，回车打开或切回已有标签，Esc 返回原视图。 |
| Qt 主窗口 | 切换主页与当前工作簿，关闭工作簿 | 工作簿标签显示文件名；修改后追加 `*`。关闭标签时只关闭对应的工作簿。关闭窗口时逐个处理工作簿的未保存修改，再退出客户端。 |
| ONLYOFFICE 编辑区 | 编辑单元格、输入公式、切换工作表 | 沿用编辑器的网格、公式栏、工具栏和工作表标签。Qt 菜单与编辑器共有的命令共用处理流程和可用状态，例如两处“保存”都反映同一份工作簿。 |
| 后续“工具”选项卡与 React 面板 | 检查、对比、预览和应用结果 | 每个业务工具在“工具”选项卡有一个主入口。需要对照工作表的任务用编辑器停靠面板，面板打开时仍可选择单元格。同一工具再次打开时聚焦已有面板、保留输入。 |
| 对话框 | 选择本地文件，处理需要立即决定的事项 | 文件选择使用 Windows 系统对话框。关闭时有未保存修改，才询问“保存 / 不保存 / 取消”。校验结果、普通成功提示放在所属区域内。 |

面板从上到下依次放工具名称、作用范围、参数、主操作和结果。窄窗口下，标签移到输入框上方，长选区和错误信息可换行；结果列表自行滚动，主操作仍可到达。面板宽度服从编辑器停靠区域，优先保留工作表的可见空间。

## 视觉与文案

启动窗口以项目固定的 ONLYOFFICE 10.0 源码为视觉基准。主页和打开页共用上游 Modern Light（`theme-white`）配色、导航图标、圆角和列表行。普通窗口优先展示文件名、位置和时间；空间不足时按可用宽度收起次要列。顶部标记、Windows 任务栏和安装包统一使用 [Excel Utils 图标](../apps/desktop/brand/excel-utils.png)。[上游启动窗口说明](https://helpcenter.onlyoffice.com/desktop/getting-started)

下列尺寸用于项目自有控件。Qt 使用逻辑像素，React 使用 CSS 像素。字体随 Windows 界面字体设置，中文使用系统字形回退；工作表内的字号、填充色始终由工作簿决定。

| 项目 | 首版约定 |
| --- | --- |
| 字号与布局 | 正文以 14 px 为基准，辅助说明 12 px，面板标题 16 px、半粗。间距用 4、8、12、16、24 px；表单控件高度以 32 px 为基准，字体放大时可增高。表单标签左对齐，同组字段保持相同的起始位置。 |
| 颜色与主题 | 自有控件共用“背景、正文、次要文字、边框、强调、错误、焦点”这些颜色用途。取值随当前编辑器主题同步。React 使用编辑器提供的主题值和 `onThemeChanged`，Qt 将同一组用途映射到调色板。主题适配只作用于应用界面。 |
| 按钮与图标 | 一个操作区只突出当前步骤的主动作，例如“开始检查”或“应用 12 处修改”。次要动作使用普通按钮。工具栏沿用编辑器风格，图标按钮同时提供提示和可访问名称，禁用动作的原因显示在邻近位置。 |
| 可读性 | 普通正文与背景对比度至少 4.5:1；用于识别控件和焦点的必要视觉线索与邻接颜色至少 3:1。错误、只读、重复等状态同时给出文字。 |
| 术语 | 菜单、按钮、提示统一使用“工作簿、工作表、单元格、选区、保存、另存为”。按钮使用动作名。错误说明对象、原因和下一步，例如“无法保存 物品表.xlsx。文件正被占用。请关闭占用程序后重试，或另存为副本。”仅在能识别占用时使用该原因。 |

主题切换和 DPI 缩放需要同时检查 Qt 窗口、编辑器及面板。在 100%、150%、200% 缩放下，文字、焦点框、按钮及列表操作都应完整可见。[ONLYOFFICE 插件主题](https://api.onlyoffice.com/docs/plugins/interacting-with-editors/overview/how-to-customize-themes) · [Qt 高 DPI](https://doc.qt.io/qt-6/highdpi.html) · [文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) · [控件对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)

## 键盘与焦点

| 场景 | 行为 |
| --- | --- |
| 打开与保存 | `Ctrl+O` 打开工作簿；`Ctrl+S` 保存当前工作簿。焦点在网格或 React 面板时，一次按键只触发一次命令。保存期间再次按键时，若工作簿有后续修改，则在本次保存结束后保存新改动；否则合并重复请求。 |
| 编辑与输入 | 方向键、复制、粘贴、撤销交给当前焦点所在的网格或输入框。中文输入法组词期间，回车先完成选词。面板输入框内的回车按字段语义处理，批量写回须明确激活“应用”按钮。 |
| 面板与对话框 | 打开面板后聚焦第一个可操作字段；用 Tab 和 Shift+Tab 按视觉顺序移动。Esc 先关闭当前下拉框或对话框，再处理外层面板。关闭后恢复到触发入口；从结果执行“定位”时，焦点交给目标单元格。 |
| 辅助访问 | 所有鼠标动作均有键盘入口，获得焦点的控件有可见焦点环。为 Qt 控件及 React 表单提供与可见标签一致的可访问名称；异步完成后播报简短结果摘要，键盘焦点留在用户操作的位置。 |

## 工具状态与数据变更

| 时机 | 应向用户呈现的行为 |
| --- | --- |
| 无文件、加载中、只读 | 没有工作簿时引导打开文件。加载中显示文件名和进度状态，编辑器就绪后启用工具。只读工作簿允许检查和定位，修改动作旁说明“当前工作簿为只读”。 |
| 无有效选区 | 主动作暂不可用，在范围字段旁说明需要的输入，例如“请选择一列 ID”。有效后立即显示工作表名与地址，例如 `物品!A2:A7`。 |
| 运行检查 | 显示“正在检查…”；能得到可靠进度时才显示百分比。执行期间防止重复提交。结果返回后显示检查范围、数量和可执行动作；零结果明确写“未发现重复 ID”。 |
| 预览与写回 | 改写数据前列出目标工作表、区域、修改数量和代表性差异。写回绑定预览时的目标和原值；切换工作簿、目标数据变化或工作表失效时，提示重新预览。改变当前选区不会把写回目标静默改到新位置。 |
| 完成与失败 | 插件显示“已应用 12 处修改”表示变更已进入当前工作簿。ONLYOFFICE 报告目标 XLSX 写入成功，且当前会话没有后续修改时，主窗口才显示“已保存”并清除星号。保存失败时保留编辑内容和星号，提供“重试”或“另存为”。只有已验证该操作能整体撤销时才显示“撤销”。 |

## 重复 ID 检查示例

用户选中 `物品!A2:A7`，依次包含 `001、014、010、001、014、030`。点击“工具 → 检查重复 ID”，面板显示该范围，主按钮为“开始检查”。检查结束后，面板保留范围，并显示以下结果。

| 重复 ID | 出现次数 | 可定位的位置 |
| --- | ---: | --- |
| `001` | 2 | A2、A5 |
| `014` | 2 | A3、A6 |

摘要为“已检查 6 个单元格，发现 2 个重复 ID，涉及 4 个单元格”。点击或用键盘激活 A5 后，编辑器选中 `物品!A5`，面板保留结果和原检查范围。需要针对另一列再检查时，用户先点“使用当前选区”。只读检查和定位都不会让工作簿出现未保存标记。

## 界面验收

| 用例 | 通过条件 |
| --- | --- |
| 本版启动页 | 初次启动时可进入“主页”“打开”和“工具”。从“打开”页选一份文件，保存退出，再启动时主页可点该文件，打开页可见其所在目录。 |
| 全键盘操作 | 仅用键盘打开样表、进入工具、执行检查、定位结果并回到网格；在网格和面板分别按一次 Ctrl+S，各只产生一次保存操作。 |
| 缩放与主题 | 在 100%、150%、200% Windows 缩放及窄窗口下检查长中文文件名、选区、错误文本和面板底部按钮。切换支持的主题后，面板、宿主、焦点和禁用态均可辨认，表格数据格式保持原样。 |
| 检查与定位 | 使用上面的六个文本值，结果数量、地址和前导零均一致。重复检查、零结果、无有效选区都给出对应反馈。 |
| 防止误写 | 对一批修改先预览，再切到其他选区、修改预览目标或打开另一个工作簿。原预览不能写入新选区或覆盖已变更的数据；只读状态仍可查看结果。 |
| 保存与关闭 | 模拟目标文件无法写入时，保留未保存标记和会话，可另存为；关闭对话框选择“取消”后返回原工作簿，内容和焦点可继续操作。 |
